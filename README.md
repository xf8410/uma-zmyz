## 每星效果（继承事件触发时）

### 蓝因子（★1-10 阶梯，effect_id=等级）
裸值 ★1..10 = 1/4/7/10/13/16/19/22/25/28；显示收益 = 裸值 + 2（即 ★1=+3、★2=+6、★3=+9 …）。
每个等级另有一条 target 61-65（亲代星数联动同属性加成）：★1-3→值1、★4-6→值2、★7-9→值3、★10→值4（显示含义待核）。

### 适性因子 / 遗传子
★1=+1、★2=+2（适性档位）。

### 比赛因子
每场 G1 固定属性组合，★1/2/3 = +3/+6/+9（直接值，例：有馬記念=根性+9）。

### 剧本因子（重点）
- 六大基础剧本（URA/アオハル杯/クライマックス/グランドライブ/グランドマスターズ/L'Arc）：双属性 **★1=+10/+10、★2=+20/+20、★3=+30/+30**（例：URA=速+耐）
- L'Arc 六子因子：单属性 ★1..5 = 1/4/7/10/13（5 级）
- U.A.F. 三因子：属性+PT ★1/2/3 = 5/10/15
- 豊食祭五因子：属性+PT ★1/2/3 = 3/6/9
- メカウマ娘五因子：属性+PT ★1/2/3 = 4/8/12
- Legends / 無人島 / 温泉郷 / Dreams / トレセン軒：双属性 **★1/2/3 = 12/24/36**
- アスリート魂（★3 限定）/ 食の極意（★3 限定）：集齐前置因子的奖励，固有技能提示

### 特殊条件因子（type 9，隐藏实绩）
- ○○の目覚め（五维）：★1/2/3 = +6/+12/+18
- ○○の目覚め（右回り/左回り/春夏秋冬）：技能提示 Lv=星
- 50022-50061（東の雄/西の雄/連戦連勝 等 40 个，succession_search_hidden=1 不进因子检索）：**随机属性 +6/+12/+18**

### 白技能因子（1337 个）
不加属性。继承成功 → 获得对应技能提示，提示等级 = 星级（1-3；因子强化后 effect 表支持到 5 级）。

### 固有因子（792 个）
继承成功 → 获得该角色固有技能提示（★1/2/3 → Lv1/2/3，★4+ 仍为 3），并附带 target 61-65 亲代星数联动属性组件。
